# Heartfelt Birthday Greeting Experience (Option A)

A mobile-responsive interactive website using the authentic video artwork.

## Flow & Features:
1. **Screen 1**: Countdown Timer & Greeting for Dhruvi
2. **Screen 2**: Dotted flight trajectory with date display
3. **Screen 3 (Option A)**: The original video artwork of the apartment window balcony across two skies. Tapping "Open the curtains" triggers the smooth curtain parting/fade reveal of the couple.
4. **Screen 4**: Birthday cake with lit candles that can be tapped to blow out
5. **Screen 5**: Celebration blast with confetti and greeting
6. **Screen 6**: Letter card with live typewriter animation
7. **Screen 7**: Rooftop skyline silhouette with pulsing heart and "Play Again" button

## How to run:
Extract the ZIP and open `index.html` in any web browser on desktop or mobile.
